## Sizing the commissioning gate

- Gate 2 is mostly a port: generalise `preflight.py` from `--station mac|pi` and `known-good.toml` to `station.toml` plus a mission-agnostic manifest, and split the GDS-dependent rows out so it can run right after the playbook.
- Gate 5 is a few lines: add an offset bound on Linux and make the macOS rows FAIL.
- Gate 4 is a new script built from `rot-test.sh`'s loop: sweep to `az_max`/`el_max` from `station.toml`, assert position within tolerance, home to `home_az/el`.
- Gate 3 is new on the receive side and needs hardware the BOM has not yet pinned (the attenuator pads) and a test frame that is not an Electra command.
- Gates 1 and 6 are new from zero. Gate 6 also needs a hardware decision (where the GPS fix comes from).
